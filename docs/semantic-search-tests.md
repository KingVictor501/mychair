# Semantic search tests

Search works by meaning: **query -> embed -> compare -> ranked passages, closest first.**
Each query is turned into 1,536 numbers by OpenAI `text-embedding-3-small`, then compared to the 232 stored passage embeddings by cosine similarity (score = 1 minus distance; closer to 1 means closer in meaning).
Corpus: the sample shop (5 files, 232 chunks). The corpus files are in this repo.
Tested on the `/search` page, top result only. The query text is not stored in the production logs; only its length, the result count, the top score and the time are.
