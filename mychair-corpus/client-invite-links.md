# Client Invite Links

A pro can send a client a link that makes sign-up quick and attaches the new client to that pro. This page explains how the links work.

## Who can make a link

A pro can make a link for their own page. An owner can make one only if they also work as a pro. Clients cannot make links. Super Admin can make a link for anyone.

## How a pro makes and shares a link

On the pro dashboard, choose Create client invite link. MyChair shows the link and a copy button. The app does not send texts or emails. The pro copies the link and sends it from their own phone, in a text, a chat, or an email.

## How long a link lasts

A client link works for 24 hours and can be used once. After 24 hours, or once someone has signed up with it, it stops working. The pro can make a new one at any time.

## When a link counts as used

A link is used only when the client's account is created successfully. If the sign-up fails, for example a typo in the phone number, the link is not used up and the client can try again within the 24 hours.

## What happens when a client opens it

The sign-up page opens with that pro already chosen. After the client finishes signing up, they are that pro's client and can book right away.

## Privacy of the link

The link is a random code. It does not contain the client's name, phone number, or email. Only a scrambled version of the code is stored. Making links is rate limited to prevent abuse.

## Link problems

If a link says it has expired or was already used, ask your pro for a new one. If you already have an account, log in and book with the pro directly.
